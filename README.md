# Learn Web Basics

An educational web design project built to introduce beginners to the basics of HTML, CSS, and JavaScript.

## Project Overview

Learn Web Basics is a front-end website that helps users start their web development journey. The website includes sections for HTML, CSS, JavaScript, quizzes, references, about, and contact pages.

The project focuses on clean page structure, visual design, navigation, and beginner-friendly content organization.

## Features

- Home page with a clear learning introduction
- Navigation menu for HTML, CSS, JavaScript, quizzes, references, about, and contact pages
- Educational content for web development basics
- Quiz section for practice
- Styled interface using CSS
- Use of images and visual sections
- Organized project structure

## Technologies Used

- HTML
- CSS
- JavaScript

## Skills Practiced

- Web page structure
- Front-end layout design
- Navigation design
- Styling with CSS
- Basic interactivity with JavaScript
- User interface organization
