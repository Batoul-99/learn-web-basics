Introduction to JavaScript

JavaScript makes web pages interactive. It can:

  • Change HTML content
  • Change CSS styles
  • Respond to user clicks and actions
  • Create animations
<script>
  document.write("Hello from JavaScript!");
</script>

Variables

Variables store data. JavaScript uses let, const, and var.

let name = "Zainab";
let age = 20;

console.log("My name is " + name);

Data Types

JavaScript has several data types:

  • String
  • Number
  • Boolean
  • Array
  • Object
let name = "Zainab";   // String
let age = 20;          // Number
let isStudent = true;  // Boolean

Arrays

Arrays store multiple values.

let colors = ["red", "green", "blue"];
console.log(colors[1]); // green

Objects

Objects store data in key–value pairs.

let person = {
  name: "Zainab",
  age: 20,
  hobby: "Coding"
};

console.log(person.name);

DOM Manipulation

The DOM allows JavaScript to change HTML elements.

<h1 id="title">Hello</h1>

<script>
document.getElementById("title").innerText = "Changed with JS!";
</script>

Events

Events respond to user actions like clicking or typing.

<button onclick="changeColor()">Click me</button>

<script>
function changeColor() {
  document.body.style.backgroundColor = "lightblue";
}
</script>

Conditionals

Conditionals let your code make decisions.

let age = 18;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

Loops

Loops repeat code.

for (let i = 1; i <= 5; i++) {
  console.log("Number: " + i);
}
