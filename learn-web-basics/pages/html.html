Introduction to HTML

HTML (HyperText Markup Language) is the standard language for creating web pages. It structures the content using tags like <h1>, <p>, and <a>.


          
            <!DOCTYPE html>
            <html>
              <head>
                <title>My First Page</title>
              </head>
              <body>
                <h1>Hello World!</h1>
              </body>
            </html>

HTML Paragraphs

Paragraphs in HTML are defined using the <p> tag. Each paragraph starts on a new line automatically.

          
            <p>This is the first paragraph.</p>
            <p>This is another paragraph.</p>

HTML Headings

Headings are defined with <h1> to <h6> tags.

          
            <h1>Heading 1</h1>
            <h2>Heading 2</h2>

HTML Links

Links are created using the <a> tag with an href attribute:

<a href="https://www.example.com">Visit Example</a>

HTML Images

Images are added using the <img> tag with src and alt attributes:

<img src="photo.jpg" alt="Description of image">

HTML Lists

HTML provides two main types of lists: ordered lists using <ol> and unordered lists using <ul>.

Unordered List (bullets)


        <ul>
          <li>Coffee</li>
          <li>Tea</li>
          <li>Milk</li>
        </ul>

Ordered List (numbers)


        <ol>
          <li>First</li>
          <li>Second</li>
          <li>Third</li>
        </ol>

HTML Tables

Tables are created with the <table> tag and organized into rows (<tr>) and cells (<td> or <th>).


          <table border="1">
            <tr>
              <th>Name</th>
              <th>Age</th>
            </tr>
            <tr>
              <td>Alice</td>
              <td>22</td>
            </tr>
            <tr>
              <td>Bob</td>
              <td>25</td>
            </tr>
          </table>

HTML Forms

Forms allow users to input data. Common elements include <input>, <label>, <textarea>, and <button>.


      <form>
        <label>Name:</label>
        <input type="text" placeholder="Enter your name">

        <label>Email:</label>
        <input type="email" placeholder="Enter your email">

        <button type="submit">Submit</button>
      </form>
