Introduction to CSS

CSS (Cascading Style Sheets) controls how HTML elements look on the page. You can use it to set colors, fonts, layouts, and animations.

            
              p {
                color: blue;
                font-size: 18px;
              }

CSS Selectors

Selectors tell the browser which HTML elements to style. Examples:

/* Element selector */
            p {
              color: green;
            }

            /* Class selector */
            .intro {
              font-weight: bold;
            }

            /* ID selector */
            #main-title {
              color: darkblue;
            }

CSS Colors

Colors can be defined using names, HEX, RGB, or HSL values:

/* Named color */
            h1 { color: tomato; }

            /* HEX */
            p { color: #0b7285; }

            /* RGB */
            div { background-color: rgb(200, 230, 255); }

            /* HSL */
            span { color: hsl(160, 60%, 45%); }

CSS Box Model

Every HTML element is a box made of content, padding, border, and margin.

div {
            background: lightblue;
            padding: 20px;
            border: 3px solid #0b7285;
            margin: 15px;
          }

CSS Fonts & Text

You can change font family, size, alignment, spacing, decoration, and more.


        p {
          font-family: "Poppins", sans-serif;
          font-size: 18px;
          text-align: center;
          letter-spacing: 1px;
          color: #333;
        }

Try It Yourself:

CSS Backgrounds

You can apply colors, images, gradients, and control their size and repeat behavior.


          div {
            background-color: lightblue;
          }

          body {
            background-image: url("background.jpg");
            background-size: cover;
            background-repeat: no-repeat;
          }

Try It Yourself:

CSS Flexbox

Flexbox makes it easy to align and position items in rows or columns.


          .container {
            display: flex;
            gap: 10px;
          }

          .box {
            width: 100px;
            height: 100px;
            background: tomato;
          }

Try It Yourself:

CSS Grid

Grid allows you to create two-dimensional layouts easily.


          .grid {
            display: grid;
            grid-template-columns: repeat(3, 1fr);
            gap: 10px;
          }
          .cell {
            background: #4dabf7;
            padding: 20px;
            color: white;
          }
